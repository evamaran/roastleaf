# Roast & Leaf – Coffee & Tea Web Store

A responsive frontend project built with a warm visual identity, clean typography, and a consistent, modern layout.
The site includes product listings, product detail pages, a cart flow, and a cohesive brand experience.

## Features
- Homepage with hero section, product carousel and call‑to‑action
- Product categories (coffee, tea, gear)
- Product cards with images, pricing, descriptions and categories for filtering.
- Product detail page
- Shopping cart page with dynamic updates and checkout page
- Responsive navigation and footer
- Consistent color palette and typography across all pages

## Technologies Used
- **HTML5**
- **CSS3** (grid, flexbox, responsive breakpoints)
- **JavaScript** (DOM manipulation for cart functionality)
- **Git & GitHub** for publishing

## API Integration
This project uses the **Noroff Online Shop API** to fetch product data dynamically.

### Endpoints used
- **Product list** – retrieves all available products
- **Single product** – retrieves detailed information for a specific product
- **Cart logic** – handled locally, but based on API product data

The API powers the product listings, product detail pages, and ensures consistent data across the site.

## Development Workflow
The project was developed with a focus on:
- Component‑based structure
- Clean, readable CSS based on pages and/or functionality
- Visual consistency across all pages
- Testing on mobile, tablet, and desktop
