# AI Usage Log

This project was developed with occasional assistance from Microsoft Copilot as a study partner.
AI was used in the following ways:

- Brainstorming layout ideas, component structure, and general project planning
- Debugging help by describing errors and asking for explanations
- Clarifying JavaScript concepts (DOM manipulation, event listeners, responsive logic, localStorage)
- Assistance with CSS adjustments, responsive styling, and visual refinements
- Help understanding API documentation
- General guidance when stuck, to understand why something did not work as expected
- AI was used to generate non-technical content such as:
	- product descriptions
	- longer product texts for product pages
	- all generic page texts (About, Contact, Terms, etc.)
	- general UI copywriting where no logic was involved

AI was **not** used to generate core application logic.
All fetch requests, cart logic, login/register handling, dynamic rendering, and API integration were written manually and fully understood.

All AI-assisted suggestions were reviewed, rewritten, or adapted to fit the project’s structure.
